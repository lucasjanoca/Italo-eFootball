# Ítalo eFootball

Site responsivo do **Ítalo Football**, desenvolvido pela **InfoTech.io**.

## Estrutura

- `index.html` — página principal e conteúdo
- `styles.css` — identidade visual, desktop e mobile
- `script.js` — menu, animações, modal e navegação
- `assets/` — imagens do projeto

## Estado atual

A base visual já está pronta para desktop e celular, seguindo a referência preto/vermelho do projeto. Curso, comunidade, vídeos, links e contato estão estruturados para receber os links e conteúdos oficiais do Ítalo.

## Próximas integrações

Substituir os dados provisórios pelos links oficiais de YouTube, Instagram, TikTok, WhatsApp/comunidade e curso.

## Publicação

O projeto é estático e compatível com GitHub Pages. Basta publicar a branch `main` a partir da raiz do repositório.
